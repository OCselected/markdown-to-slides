# [输入给 NotebookLM / AI 图像生成引擎的系统提示/背景信息]

## 文档用途
用于和读书思考爱好者的交流（Deck）。

## 使用场景
「开源之道」日常交流 / 「OSCAR·开源之书·共读」meetup 分享

## 听众画像
思考者，阅读者，善于交流者。对制度经济学、开源文化、人类学有基本的认知框架。

## 讲者视角
思维活跃者、独立开源研究者、协作机制设计师（社会黑客）。

## 核心诉求
展示一种新型的人机协作阅读方式——不是用AI替代阅读，而是用AI记录认知跳跃。

## 核心基调
dark academic tone, Intellectual Visual System, art taste.

## 视觉风格关键词
- 包豪斯几何构成（Bauhaus geometric composition）
- 深普鲁士蓝 #1B3B6B 作为强调色——代表智识深度与学术传统
- 暖白底色 #F5F0E8，羊皮纸质感——书本与经卷的联想
- 极简主义排版，大字号标题，宽松行距
- 深色学术风格（dark academic），理性、克制、智识感
- 几何抽象元素——圆、方、线作为装饰，不依赖图标

# 幻灯片大纲内容 (Slide Deck Outline)

## Slide 1: 封面 (Cover)
* **主标题：** 用 Hermes Agent 读书——一种新的阅读方式
* **副标题：** 阅读断点、桥接概念与知识网络的生长
* **讲者信息：** 「开源之道」·适兕
* **时间/地点：** 2026.7.18 · OSCAR 分享

## Slide 2: 问题：多书并行的阅读者
* 视觉隐喻：
  * 一个人同时翻开三本书，脑袋里出现三条不同的思路——不是分心，是连接
* 显示要点：
  * 同时阅读 4-8 本书的研究者，经常从一本书「跳跃」到另一本
  * 这种跳跃通常被视为「分心」——但记录跳跃发生时在想什么，会发现跳跃不是分心，是直觉在尝试连接两个知识域
  * 问题是：用豆瓣标记「在读」只能记录读了什么，不能记录为什么跳过去
  * 需要一种工具：**记录认知跳跃轨迹，捕捉桥接概念**

## Slide 3: 解决方案：阅读断点（Reading Breakpoints）
* 视觉隐喻：
  * 调试器中亮着几个断点的代码编辑器——断点捕获程序状态，阅读断点捕获思想状态
* 显示要点：
  * 借鉴 debug 中的断点概念——不是在跳跃时「停下来」，而是在跳跃时捕获**现场状态**
  * 每次跳跃记录 5 个字段：当前书、关键洞察、跳跃触发、目标书、**桥接概念**
  * 桥接概念是系统的灵魂——不是记录读了什么，而是记录什么想法让你从 A 到了 B
  * 积累的不是书评，而是一张思想的连接网络

## Slide 4: 哲学基石（三个支柱）
* 视觉隐喻：
  * 三根立柱支撑一座屋顶——每根柱子上刻着一个命题
* 显示要点：
  * **核心命题**：人类的知识是连接起来的网络。每本书、每位作者、每个章节都是其中一个节点。读书就是点亮这些节点，找到联系
  * **核心方法**：把一本书读「厚」——不是提炼结论，而是找到它与其他书的连接、发现它背后的制度条件、追问它没有回答的问题
  * **核心根由**：读书不是为了比较哪个视角「对」，而是为了站得更高、更远，减少盲区。多视角不是为了选边站，而是为了让不可见变得可见

## Slide 5：五天五条断点
* 视觉隐喻：
  * 一张知识地图，上面有 5 个标记点，每个标记点之间有连线——连线比点更重要
* 显示要点：
  * BP-001（7/10）：NIE导论 → Ostrom传记 —— 桥接概念：**理论生成的制度条件**
  * BP-002（7/10）：Ostrom制度定义 → 人类学 —— 桥接概念：**制度的多面体**
  * BP-003（7/10）：Ostrom传记 → Graeber —— 桥接概念：**制度的双面光谱**
  * BP-004（7/12）：Engelhardt论文 → Walker睡眠科学 —— 桥接概念：**受限即可能**
  * BP-005（7/14）：XX经济学书目 → 大侦探经济学 —— 桥接概念：**经济学作为启蒙工具**
  * 5 条断点形成了链条型跳跃——每次跳跃都在前一次的基础上递进追问

## Slide 6：阅读的工具管线
* 视觉隐喻：
  * 一条输送带：书→摘抄→wiki条目→slide格式→NotebookLM→视觉演示文稿
* 显示要点：
  * 摘抄 → Hermes自动格式化为 `daily-reading/YYYY-MM-DD.md` 的 Slide 条目
  * 每张 Slide 包含：视觉隐喻 + 显示要点 + 开源之道感慨 → 直接输入 NotebookLM
  * wiki 条目 → `wiki-to-slides.py` 自动转换 → 标准化 Slide 格式
  * 15 张 Slide 为一组，每日独立文件，自然延伸
  * 所有输出提交到 git 仓库（`OCselected/markdown-to-slides`）

## Slide 7：系统架构概览
* 视觉隐喻：
  * 三台机器通过管道相连——一台是阅读输入（Hermes Agent），一台是知识存储（LLM Wiki），一台是输出引擎（Git + NotebookLM）
* 显示要点：
  * **Hermes Agent**（个人AI助理）：接收摘抄 → 格式化为 Slide → 记录断点 → 提交 git
  * **LLM Wiki**（Google Drive）：永久知识存储——书籍条目、概念页、断点日志、引用谱系
  * **markdown-to-slides**（GitHub Repository）：Slide 模板 + 每日阅读记录 + wiki转换脚本 + 分享 Deck
  * **ttoos**（GitHub Repository）：Hugo 博客——每日开源推荐发布到博客
  * **Cron Job**：每日 07:30 自动运行——推荐书籍 → 生成 SVG 卡片 → 写入 wiki → 发布博客 → git commit + push
  * 核心设计原则：**一次输入，多点输出**——一次摘抄同时进入每日记录、wiki 条目、blog 文章

## Slide 8：系统架构图（技术细节）
* 视觉隐喻：
  * 一个数据流图，箭头从输入指向多个输出，每个节点标注了工具名称
* 显示要点：
  * **输入层**：用户分享摘抄（Feishu/微信）→ Hermes Agent 接收
  * **处理层**：Hermes 格式化→ `daily-reading/YYYY-MM-DD.md`（Slide格式）→ 同时写入 wiki 推荐条目
  * **自动管线（Cron Job）**：
    - `generate-rec-card.py`：生成 600×800 深普鲁士蓝 SVG 卡片
    - `wiki-to-slides.py`：wiki 条目 → 标准化 Slide 格式
    - `daily-book-paper-check.sh`：检查 wiki 已有条目，避免重复推荐
    - 全部写入后自动 `git add + commit + push`
  * **输出层**：
    - GitHub: `OCselected/markdown-to-slides`（每日阅读记录）
    - GitHub: `OCselected/ttoos`（Hugo 博客文章 + SVG）
    - GitHub: `OCselected/open-source-reading`（reading-breakpoints skill）
    - Google Drive: LLM Wiki（概念图谱 + 引用网）

## Slide 9：Git 仓库结构与工作流
* 视觉隐喻：
  * 三个并排的仓库，每个仓库里放着不同类型的文件——读书笔记、博客文章、技能文件
* 显示要点：
  * **仓库 1：`OCselected/markdown-to-slides`**
    - `daily-reading/`：每日阅读笔记（按日期命名，15张slide上限）
    - `slides/`：wiki 推荐条目的批量 Slide 输出
    - `osbook-sharing/`：分享 Deck
    - `wiki-to-slides.py`：wiki 转换脚本
    - `template.md`：统一 Slide 模板
  * **仓库 2：`OCselected/ttoos`**（Hugo 博客）
    - `content/posts/osbook-book-recommendation/`：每日推荐博客文章
    - `static/media/`：SVG 视觉卡片
    - 标题格式：`2026年7月13日，「开源之书」今日推荐：《书名》`
  * **仓库 3：`OCselected/open-source-reading`**
    - `skills/reading-breakpoints/`：阅读断点方法论
    - 哲学三支柱 + 工作流规则 + 发布渠道
  * Git 规则：禁止 `git add -A`，只允许 `git add <具体路径>`

## Slide 10：Cron Job 自动化管线
* 视觉隐喻：
  * 一个自动化的工厂流水线，每天 07:30 准时启动——从原料到成品无人值守
* 显示要点：
  * **触发**：每日 07:30（北京时间），`schedule: "30 7 * * *"`
  * **步骤 1**：从 wiki 素材库选择推荐书籍（按优先级：第二梯队 → 信任谱系 → 论文轮换）
  * **步骤 2**：生成 SVG 卡片（`generate-rec-card.py`，深普鲁士蓝 #1B3B6B 配色）
  * **步骤 3**：写入 Hugo 博客文章（`date: 当天07:00`，比运行时间早30分钟确保 Hugo 显示）
  * **步骤 4**：写入 LLM Wiki（推荐条目 + log.md + index.md）
  * **步骤 5**：git add + commit + push（博客文章 + SVG 卡片）
  * **步骤 6**：推送飞书/微信群聊（MEDIA: 路径 + 推荐文案 + 金句）
  * 全流程约 2-3 分钟，无人值守，自动运行

## Slide 11：知识演化管线——从摘抄到永久知识
* 视觉隐喻：
  * 一条河流从源头到入海口——源头是阅读时的灵光一闪，入海口是 wiki 中固化下来的概念节点
* 显示要点：
  * **瞬间**：阅读时产生摘抄或感慨 → 告诉 Hermes
  * **分钟**：Hermes 格式化为 Slide → 追加到当日 `daily-reading/YYYY-MM-DD.md` → git commit
  * **小时**：如果摘抄涉及新书 → 创建 wiki 推荐条目（含 frontmatter、核心概念、开源映射）
  * **天**：Cron Job 自动从 wiki 素材库中选择推荐 → 生成 SVG 卡片 → 发布博客
  * **周**：积累的 Slide 达到 15 张 → 封存为完整 Deck → 输入 NotebookLM 生成视觉演示
  * **年**：断点累积到足够数量 → 分析跳跃模式 → 形成个人阅读认知图谱
  * 核心设计：**从瞬时灵感到永久知识的五个时间层**，不需要手动整理

## Slide 12：66 本在读清单的结构
* 视觉隐喻：
  * 七层同心圆，从内到外密度递减——最内层是制度经济学，最外层是健康与科幻
* 显示要点：
  * **内圈**（15本）：NIE 核心——威廉姆森、North、Ostrom、Greif、Eggertsson、Aoki
  * **第二圈**（12本）：经济史与技术史——Pomeranz、Landes、Mokyr、Lipsey
  * **第三圈**（10本）：开源、公地与IP——Weber、Birkinbine、Kelty、Boyle
  * **第四圈**（9本）：认知、演化与系统——Simon、Meadows、Deutsch
  * **外圈**：启蒙思想史、健康与生物、战略与商业
  * 核心发现：不读「如何做开源」，而是用制度分析 + 经济史 + 认知科学来解剖它

## Slide 13：XX 经济学的谱系
* 视觉隐喻：
  * 一棵树，树干写着「经济学」，树枝延伸到幸福、犯罪、AI、公地、海盗、甜甜圈……
* 显示要点：
  * 不存在一种经济学 Rule Them All。每种「XX 经济学」都是一个特定的问题框
  * 第一类：用工具分析新领域（幸福经济学、AI经济学、公地经济学）
  * 第二类：挑战主流范式（甜甜圈经济学、复杂经济学、演化经济学）
  * 第三类：用一个概念统一切面（海盗经济学、Token经济学、助推）
  * **开源经济学属于这个家族**——它不是又一个标签，而是在追问：没有雇佣关系、没有层级命令、没有价格信号的世界，协作如何可能？

## Slide 14：第一天——Ostrom 到 Graeber
* 视觉隐喻：
  * 同一座雕塑的两面——一面是农民围坐协商，一面是柜台前排队的市民
* 显示要点：
  * 从 Ostrom 传记开始：普通人不需要官员替他们治理，他们有自我治理的能力
  * 跳跃到 Graeber：官僚制设置不可能的标准然后责怪个人
  * **制度的双面光谱**：Ostrom 看到制度作为协作的处方，Graeber 看到制度作为暴力的仪式
  * 读懂制度，必须同时读这两个人

## Slide 15：第二天——North 的制度变迁
* 视觉隐喻：
  * 一块巨石投入湖面，激起的涟漪缓慢扩散，而非瞬间消失
* 显示要点：
  * North 的核心命题：**制度分析不是研究博弈规则，而是研究个人对这些规则的反应**
  * 规则可以即时改变，但个人对规则变化的反应是一个极其复杂和缓慢的适应过程
  * North 的《理解经济变迁过程》：制度是「为减少不确定性而施加于生活之上的结构式命令」
  * 语言、物理制品、信念都是制度载体——文化作为 L1 层几乎决定了一切
  * 《西游记》结构：等级天经地义的文化编码

## Slide 16：第三天——Engelhardt 论文与 Williamson 框架
* 视觉隐喻：
  * 四层同心圆，最外层模糊不清，最内层清晰锐利
* 显示要点：
  * Engelhardt & Freytag (2013) 检验了四个假设：自我决定文化、竞争态度、经济管制、人际信任对开源贡献的影响
  - **文化因素是开源贡献的重要解释变量**——与 North 的 L1 层完全吻合
  * Williamson L1-L4 框架：人们在 L4（资源配置）挣扎，却不知道决定性的力量在 L1-L3
  * 大分流命题：中国搭了开源的技术便车，但缺少治理认知——不是技术问题，是制度问题

## Slide 17：第四天——有限理性与制度的起源
* 视觉隐喻：
  * 两个赛跑者，一个有地图但看不清路，另一个没有地图但腿脚灵活
* 显示要点：
  * 威廉姆森用两个概念把握人类本质：**有限理性** + **投机**
  * 有限理性：人的领悟能力是有限的——不是不想算清楚，是算不清楚
  * 投机：用「机敏」（subtlety）取代了「赤裸裸的自身利益追求」
  * 如果人无限理性，不需要制度。如果人没有投机倾向，靠信任就够了。
  * **因为两者同时存在，制度才成为必要**
  * 西蒙（1968）：思想也是稀缺资源。如果思想稀缺却没有自由的思想市场（科斯），有限理性的最优策略就是停止思考

## Slide 18：每日阅读记录——一条连续的认知流
* 视觉隐喻：
  * 一条河流，每天的记录是河床上的一个横截面——每个截面不同，但水流是连续的
* 显示要点：
  * 7/10 制度的一日巡礼（Ostrom→Graeber，12张slide）
  * 7/12 Engelhardt论文 + North 制度变迁（7张slide）
  * 7/13 North 微观基础 + 制度的累积结构（5张slide）
  * 7/14 Rust Feeling Economy → RDD → Raworth → 威廉姆森（9张slide）
  * 7/15 Lowe服从 → Weber丰田类比 → Moody共同信念 → Lerner组织创新（5张slide）
  * 一日不中断，每日记录独立，15张上限自然轮换

## Slide 19：过去一周的阅读网络
* 视觉隐喻：
  * 一个不断扩展的星座图，每本书是一颗星，阅读断点是连接它们的线
* 显示要点：
  * 7天内跨越的领域：NIE → 经济史 → 人类学 → 睡眠科学 → 情感经济学 → 信息规则 → 法律史 → AI经济学 → 演化经济学
  * 跨越的时间跨度：从 Lowe（1965）到 Lerner & Tirole（2002）到 Rust（2021）
  * 跨越的文化：从秘鲁灌溉渠（Ostrom）到中世纪热那亚（Greif）到日本丰田（Weber）
  * 桥接概念谱系：理论生成的制度条件 → 制度的多面体 → 制度的双面光谱 → 受限即可能 → 经济学作为启蒙工具

## Slide 20：核心收获与延伸思考
* 视觉隐喻：
  * 一个人站在山顶，前方不是更清晰，而是看到更多看不清的山脉——然后知道该往哪里走了
* 显示要点：
  * **不要听一个公司说什么开源，看他们是什么样的组织。** 组织形态才是真正的制度表达
  * **有限理性不是缺陷，是优势。** 将开源视为免费技术获取，是有限理性的自然结果。看得更多需要信念和训练
  * **不用回流验证。** 阅读不是考试，不需要每 10 条断点复盘一次。以年为单位，让连接自然生长
  * **「The Economics of Open Source」不是又一个标签**——它是关于「没有雇佣关系、没有层级命令、没有价格信号的世界，协作如何可能」这个问题
  * 讨论问题：你最近的阅读中有没有过「跳跃」？那个跳跃发生时，你在想什么？
