# 7/18 OSCAR 分享 — Hermes Agent 参与方案

## 方案：远程智囊团模式

### 会前准备（今天和明天完成）

**① 预判问题清单** — 准备 10-15 个可能被问到的问题和参考答案，方便你现场快速查阅

**② 现场实时响应通道** — 讨论中参与者提问时，你可以通过飞书/微信快速将问题转发给我，我即时回复（秒级）。适合：
- 被问到不熟悉的文献细节时
- 需要快速引用某本书的具体观点时
- 需要计算或对比数据时
- 现场有人提出反对意见需要即时回应时

**③ 会后总结** — 活动结束后，将讨论内容发给我，我可以：
- 整理成 slide 格式追加到分享 Deck
- 提取讨论中涌现的新桥接概念
- 形成交流纪要

### 现场互动方式建议

| 场景 | 操作方式 | 我的响应 |
|------|---------|---------|
| 有人问一个具体文献问题 | 飞书/微信转发给我 | 即时回复摘要 |
| 有人提出一个反对意见 | 发给我关键论点 | 提供制度分析框架下的回应思路 |
| 有人想了解某个阅读断点的更多细节 | 告诉我断点编号（如 BP-003） | 提供完整上下文 |
| 讨论中涌现了新的想法 | 一句话描述给我 | 现场格式化为 slide 条目 |

1. 这个方案是否可行？
2. 需要我现在开始准备预判问题清单吗？
3. 现场有没有特定的设备或网络条件限制？
