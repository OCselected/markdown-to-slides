## Slide 2: 书摘——Agent = Model + Harness，写作也是

* 视觉隐喻：
  * 一个 Agent 的解剖图——中心是"大脑"（LLM），环绕着"上下文"、"工具"、"约束"、"验证"、"纠正"五层外壳。旁边，一个人的解剖图——中心是"大脑"，环绕着"阅读"、"经历"、"实践"、"健康"、"自律"、"被爱"、"约束"。两个结构完全一样。画面下方：**"最小可工作的 Agent 只需要 LLM、上下文与工具；最小可工作的人，还需要更多。"**
* 显示要点：
  * **书摘：** Agent = LLM + [上下文 + 工具 + 约束 + 验证 + 纠正] = Model + Harness。最小可工作的 Agent 只需要 LLM、上下文与工具就能跑起来；而要让它在生产环境中长期可靠运转，还需要补全约束、验证、纠正这三层工程外壳——约束防止越界、验证发现错误、纠正恢复异常。这三层机制不是新增的"独立模块"，而是围绕"上下文 + 工具"构建的保障层。最小公式是 Demo 视角，扩展公式是生产视角；后者完全包含前者，并在外围加了一圈安全网。——李博杰《深入理解 AI Agent》
  * **「开源之道」·适兕评论：** 这像极了人的一生，不能光是有一个聪明的大脑，还需要自律、情绪、健康、社会氛围等诸多因素，才能真正做到一件事，例如写作。**写作 = 大脑 + 阅读 + 经历 + 实践 + 健康 + 自律 + 被人爱 + 约束。** 适兕的"写作公式"是对李博杰"Agent公式"的完美映射——**大脑是 LLM，阅读是上下文，经历是工具，实践是验证，健康是约束，自律是纠正，被人爱是社会氛围，约束是安全网。** 李博杰说"最小公式是 Demo 视角，扩展公式是生产视角"——**写作也是一样：一篇文章（Demo）只需要大脑+阅读+经历，但持续写作（生产）还需要健康、自律、被爱、约束。** 大分流 2.0 的启示：**中国开源的问题，不是"没有大脑"（不缺聪明人），而是"Harness 缺失"——缺乏约束（社区自治规则）、验证（代码审查）、纠正（社区共识）这三层保障。没有 Harness 的开源，就像没有自律、健康、被人爱的人生——有大脑，但活不长。**
  * **Bridge — Harness 的制度意义（The Institutional Meaning of Harness）：** 李博杰的"Harness"概念，在制度经济学中对应的是**制度基础设施**。LLM 是"技术"，Harness 是"制度"。**开源社区的成功，不是因为"代码写得好"（LLM 好），而是因为"制度设计得好"（Harness 好）——GPL 是约束（防止闭源），代码审查是验证（保证质量），社区共识是纠正（解决冲突）。** 没有 Harness 的 Agent 只能跑 Demo，没有制度的开源只能做 Demo。**大分流 2.0 的 Harness 缺失：中国开源有 LLM（聪明人、代码、技术），但 Harness 缺失（缺乏社区自治规则、缺乏代码审查文化、缺乏共识机制）。** 适兕的"写作公式"——**写作 = 大脑 + 阅读 + 经历 + 实践 + 健康 + 自律 + 被人爱 + 约束**——比李博杰的"Agent公式"更深刻，因为它包含了"被人爱"（社会认可）——这是制度经济学中"信任"和"社会资本"的微观基础。**没有社会认可的制度，就像没有"被人爱"的写作——可以产出，但无人阅读。**
  * **窄廊提问：** 如果"中国开源"缺少 Harness，那「开源之道」的工作——是帮它补上 Harness，还是让它意识到自己缺少 Harness？

## Slide 3: 解读——林桥津《智能简史》：五次突破框架与制度的跳级困境

* 视觉隐喻：
  * 一座五层宝塔，底层写着"转向"，第二层"强化"，第三层"模拟"，第四层"心智化"，顶层"语言"。一个巨大的 AI 模型站在塔顶，说"我会写诗了"，但塔基的三层是空的。画面下方：**"AI 能写诗但装不了洗碗机——中国开源能写报告但装不了社区。"**
* 显示要点：
  * **原文：** CSDN 采访林桥津（剑桥神经科学家、港科大助理教授、Max Bennett《智能简史》译者）
  * **核心框架：** 大脑进化的五次突破——**转向（线虫的二进制决策）→ 强化（鱼类的学习）→ 模拟（哺乳动物的世界模型）→ 心智化（灵长类的意图揣测）→ 语言（人类的知识传承）**。每一次突破都建立在前一次的基础上，**不能跳级**。
  * **罗西悖论：** AI 能下赢国际象棋但装不了洗碗机——因为 AI 跳过了前四次突破直接模仿语言（第五次），看起来聪明实则脆弱。
  * **与威廉姆森框架的并行：** Bennett 的"五次突破"和 Williamson 的"四层社会分析"是同一类思考工具——**复杂系统是层层叠加的，跳级必出问题。** 中国开源试图跳过 L1（黑客伦理）和 L2（社区制度），直接进入 L5（政策指令输出）——结果和 AI 一样：能写报告，但做不了社区。
  * **林桥津最精彩的判断：** "AI 在与人的交流中，总会给出'最恰当的回应'。但人与人之间，有时候一句实话会让你不舒服，但这恰恰是成长——你的想法被挑战了。" 这与适兕的"写作公式"（被人爱+约束）形成共振——**开源社区真正的价值不是"最恰当的回应"（KPI 最优解），而是"让人不舒服但让人成长"的回应（代码审查中的批评、社区共识中的冲突）。**
  * **窄廊追问：** 如果 AI 的"跳级困境"是"跳过前四次模拟直接学习语言"，那中国开源的"跳级困境"是跳过什么？——是跳过"社区自治的学习过程"，直接进入"政策指令的输出阶段"。

## Slide 4: 适兕感慨——人的有限性与社会的组成方式

* 视觉隐喻：
  * 一个人站在山顶，俯瞰脚下的世界。他手中有一本书，书上写着"一点知识"。他试图用这"一点知识"去指导山下的每一条路、每一座房子、每一个人。山脚下，人群在街道上走着，每个人都有自己的路——不是因为他指的路，而是因为社会的无数种组成方式（宗教、政党、开源、体育、艺术、资本、公司……）早已在运行。画面下方：**"不要因为有了俯瞰世人的点滴知识，就想僭越去指导一切。"**
* 显示要点：
  * **适兕感慨：** 当我们去复盘自己的人生轨迹，对某些事情后悔不已的时候，其实大可不必，因为人不能用当下的经验和心智去衡量过去的所有，这是自然赋予我们的有限性，我们的大脑的注意力总是有限，学习到的知识到应用知识只能解决一个问题，而我们的世界有无数的问题，这也是人类为了抵抗这种有限性，而组成了社会，组成社会的方式有很多，宗教、政党、开源、体育、艺术、资本、公司等等。所以，不要因为有了俯瞰世人的点滴知识，就想僭越去指导一切！人类的利他是有充足的理由成为地球的霸主的。
  * **适兕的深层判断：** 这段话把"人的有限性"和"社会的多样性"联系在了一起——**人不是全知的，所以人需要组成社会。但社会不是只有一种组成方式。** 宗教、政党、开源、体育、艺术、资本、公司——每一种都是"组成社会的方式"，每一种都在解决"人的有限性"这个问题。**"不要因为有了俯瞰世人的点滴知识，就想僭越去指导一切"——这是对"知识分子傲慢"的尖锐批评：** 当你只读了几本书、懂了一点制度经济学，就以为可以"指导"整个开源生态时，你就犯了"僭越"的错误。**"人类的利他是有充足的理由成为地球的霸主的"——这是对"经济人假设"的回应：** 人不是只会利己的理性人，利他能力是人类成功的核心——因为利他让知识可以传承、让社会可以协作、让文明可以累积。
  * **Bridge — 有限理性与制度多样性（Bounded Rationality and Institutional Diversity）：** 适兕的感慨触及了制度经济学的核心命题——**有限理性（Bounded Rationality）**。Simon（1947）说"人的认知能力有限，无法处理所有信息"，因此需要制度来简化决策。适兕说"我们的大脑注意力总是有限，学习到的知识到应用知识只能解决一个问题"——正是有限理性的定义。**而"组成社会的方式有很多"——宗教、政党、开源、体育、艺术、资本、公司——每一种都是"有限理性的应对机制"，每一种都是一种"制度选择"。** 没有一种制度可以解决所有问题，没有一种组织方式可以"指导一切"——**"僭越"的本质，是误以为自己的制度视角可以替代所有制度视角。** 大分流 2.0 的僭越：**行政式开源试图用"一种组成社会的方式"（行政指令）去指导"另一种组成社会的方式"（开源社区）——这是制度层面的僭越。**
  * **窄廊提问：** 如果"人的有限性"意味着"没有一个制度可以指导一切"，那「开源之道」的工作——知道"开源不是万能的"——这本身，是不是一种"利他"？

## Slide 5: 适兕感慨——花钱听课买的是一种思维方式，不是知识

* 视觉隐喻：
  * 一座黄土地上的窑洞，洞门口挂着"辛庄课堂"的牌子。洞里，一位学者在讲课，台下坐满了人——企业家、工程师、学生。他们不是来记笔记的，而是来"换一种看世界的方法"的。洞外，主流学界的高楼大厦里，这位学者被边缘化。画面下方：**"人们花钱听课，为的是一种思维方式和看世界的方法。"**
* 显示要点：
  * **原文：** 辛庄课堂七期班招生启动（2026-05-14）。张维迎、周其仁等创办的"辛庄课堂"，在窑洞文化中讲授企业家精神、博弈论、制度经济学。
  * **适兕感慨：** 张维迎教授绝对是近年来被主流边缘化的学者了，但是我们仍然能从民间找到思想的价值，为什么那么多人要花钱去听课？为的不就是一种思维方式和看世界的方法吗？这让我继续《开源经济学》有了动力！我们不能去提供骗人的伎俩，一条完全行不通的道路，看着他们沉沦，确实有点不道德，问题是他们没有沉沦，他们在享受整个腐败的过程。
  * **适兕的深层判断：** 张维迎被主流边缘化，但民间愿意花钱听他的课——**因为人们买的不是"知识"，而是"思维方式和看世界的方法"。** 知识可以被替代（AI 时代尤其如此），但"看世界的方法"不可替代——它决定了你如何理解问题、如何做判断、如何选择。**这给适兕继续《开源经济学》提供了动力：开源经济学提供的不是"骗人的伎俩"（一条完全行不通的道路），而是一种"看开源世界的方法"。** 最后一句最锋利："看着他们沉沦，确实有点不道德，问题是他们没有沉沦，他们在享受整个腐败的过程。"——**这不是"受害者值得同情"，而是"享受者不可救药"。** 当一个人享受着腐败的过程，任何"启蒙"都是徒劳——因为启蒙的对象是"愿意被启蒙的人"（徐贲），而"享受腐败的人"不愿意被启蒙。
  * **Bridge — 思想的市场与知识的替代（The Market for Ideas and the Replacement of Knowledge）：** 适兕的感慨触及了一个深刻的制度问题：**知识可以被替代，但思想方式不可替代。** 在 AI 时代，知识（fact）的边际价值急剧下降——AI 可以瞬间提供任何事实。但"看世界的方法"（framework）的价值不但没有下降，反而上升——因为当知识免费时，如何理解知识、如何判断、如何选择，成了真正的稀缺品。**张维迎的课卖的正是"框架"——博弈论、制度经济学、企业家精神——这些是"看世界的方法"，不是"可以查到的知识"。** 开源经济学也一样：它提供的不是"开源的知识"（可以查），而是"理解开源制度的方法"（不可查）。**"享受腐败的人不可救药"——这是对"启蒙"的一次诚实反思：启蒙有边界，它只能作用于"愿意被启蒙的人"。** 大分流 2.0 的启示：不是"中国开源的人需要被教育"，而是"中国开源的人里，有多少是愿意被教育的"。**
  * **窄廊提问：** 如果"享受腐败的人不可救药"，那「开源之道」的读者——是"愿意被启蒙的人"，还是"享受腐败的人"？而窄廊自己——是在"启蒙"，还是在"对愿意被启蒙的人说话"？


## Slide 6: 书摘——复杂不可消除，只能被驾驭

* 视觉隐喻：
  * 一群人站在一片混乱的森林前。森林里，树根交错、藤蔓缠绕、野兽潜伏。人们说："怎么才能消除这片复杂？"一个人回答："你不能消除它，你只能学会在其中行走。"他走进森林，在混乱中找到了一条窄廊——窄到只能容一个人通过，但足够让他走向远方。画面上方：**"在窄廊中获得自由和发展。"**
* 显示要点：
  * **书摘：** 当管理者和政策制定者听到"复杂性研究"时，他们常常问："我如何控制复杂性？"他们的意思通常是"我如何消除它？"。但复杂性源于根本性的原因，无法完全消除。虽然复杂性常被视为负担，但它实际上可以是资产。本书的核心论点是：**复杂性可以被驾驭。** 因此，我们不寻求消除复杂性，而是探索如何利用复杂适应系统（CAS）的动态力量来达成建设性目标。——Robert Axelrod & Michael D. Cohen, Harnessing Complexity
  * **「开源之道」·适兕评论：** 人渴望某种简单，因为复杂需要太多的能量去认知和解决，人们渴望这个世界只要一个 LLM 就足够了，然后自己躺着享受。开源意味着复杂，在各种混乱中寻找秩序，在窄廊中获得自由和发展。
  * **Bridge — 复杂性的制度价值：** Axelrod 和 Cohen 的"驾驭复杂性"与 Williamson 的"治理结构选择"是一致的——**制度不是消除复杂性的工具，而是在复杂性中建立秩序的工具。** 开源社区的制度（GPL、do-ocracy、code review）不是"消除复杂"的，而是"在复杂中建立可通行的秩序"的。**窄廊不是"窄在唯一能走的路"，而是"窄在必须遵守的规则，但宽在可以选择的方向"。** 适兕说"在窄廊中获得自由和发展"——**这是对"窄廊"概念最精准的定义：窄廊是秩序的边界，自由是在边界内的无限可能。**
  * **窄廊提问：** 如果"复杂不可消除，只能被驾驭"，那「开源之道」的工作——是"消除复杂性"（给中国开源一个简单的答案），还是"帮助人们学会在复杂中行走"（提供一条窄廊，而不是一条高速公路）？
