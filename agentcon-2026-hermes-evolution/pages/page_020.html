01 消息网关一栏 MESSAGING
把 Agent 塞进用户已经在用的通道——不是新增入口，而是接入既有入口：
CLI Telegram Discord Slack WhatsApp Signal Matrix Mattermost Email SMS Teams Google Chat
02 本土 IM 五件套 CN-FIRST
「不是附属翻译，是一等公民」
五件套与海外通道共享同一 Agent 内核、同一工具链、同一记忆空间——本地化不是"阉割版"，是与英文入口对等的原生接入：
Feishu WeCom Weixin QQ Bot DingTalk
03 终端执行后端 RUNTIME
六种执行环境覆盖从笔记本到沙箱到 serverless 的完整谱系：
本地 Docker SSH Daytona Singularity Modal
Daytona + Modal 提供 serverless 持久化——按请求冷启动，状态与凭据落盘，Agent 会话不随进程消亡。
04 操作系统覆盖 PLATFORM
跨终端 / 服务器 / 移动 / 不可变系统的完整覆盖，让 Agent 在用户机器生态中无所不在：
Linux macOS WSL2 Windows Native 早期测试 Android (Termux) Nix & NixOS
从 Windows Native 到 Android Termux，Agent 的存在形态贴近用户日常。
05 文档 i18n 一级入口 /DOCS
/docs/zh-Hans/ 是与英文入口完全对等的一级路径——不是 /docs/en/zh/ 这类子目录翻译，而是与英文并列的原生栏目。
/docs/ /docs/zh-Hans/ /docs/en/
路径即态度——中文读者不需要"翻"英文，他们直接抵达自己的文档。
06 制度含义 INSTITUTION
「操作进化不是功能堆砌，是把 Agent 塞进用户已经存在的接入路径——交易成本的最小化」
每一条接入通道的价值不在于"支持"，而在于让用户不必切换身份——不必新装 App、不必新建账号、不必改变既有协作惯例。
「 」
不是"我能做什么"·是"我在哪里等你"——Agent 只有先塞进用户已经存在的接入路径，才会被真实使用；这也是消费侧采纳率背后的制度基础。
