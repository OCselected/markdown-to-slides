DEMAND SIDE · 需求侧
#107070
P1 risk-session-state Session Replay
会话重放污染历史（session history）的 P1 缺陷。
当历史被回放或重演时，Agent 的记忆被外部状态覆盖或错位。
——暴露可靠性问题的需求侧信号。
暴露方向 历史完整性 · 可信任
01
可靠性 · 定义
可靠性不是 "能不能用"，而是 "能否信任 Agent 记住正确的历史" —— 一次正确的回答只是功能，一致且可回放的历史才是底线。
02
制度 · 含义
可靠性是 Agent 的底线，也是用户信任的前提。信任一旦破裂不可恢复 —— 底线之上才有体验，才有交付，才有合作。
SUMMARY · 收束
可靠性是 Agent 的底线。 Tenacity Release 以 Kanban 多 Agent 平台解决任务持久性，#107070 暴露会话重放污染历史的 P1 缺陷 —— 供给侧与需求侧共同构成完整画面。
