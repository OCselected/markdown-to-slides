田野考察方法论

把 issue / PR / release 当文化现象
方法论摘要

本演讲采用田野考察方法，把 Hermes 的 issue / PR / release 当作文化现象的标本，而不是数据点。每个案例都按"现象 → 数据 → 制度解读"三段式呈现。

II. 五 · 个 · 要 · 点 PRINCIPLES · 05
01
田野考察
类似人类学 / 社会学对仪式、禁忌、符号的观察方式，而非工程视角下的功能清单。
02
不是数据观察
数据点没有故事，文化现象才有说服力。孤立数字不解释人，符号才解释人。
03
案例驱动
每个案例都是一次田野观察：现象 → 数据 → 制度解读。
04
消费侧信任
feature issue 自带的安全边界标签，是"信任信号"的可观察证据。
05
命名 release
Judgment / Tenacity / Surface / Velocity / Quicksilver 等命名本身就是文化事件。
看仪式，才能读懂文明
