# 开源之书 · PPTX→Markdown 归档

来自「开源之书·共读」读书会多年积攒的 PPTX 材料，经 `kaiyuan_pptx_pipeline.py` 提取文字、视觉描述后转为 markdown，存入本目录。

**来源**：`~/onedrive/开源之书/` 下 111 份 PPTX（排除模板/海报）

**处理状态**：已迁移 70 份（截至 2026-08-13，管道仍在跑）

**目录结构**：`<year>/<deck-slug>/<deck-slug>.md`

**用途**：作为 `open-source-way-wiki` deep review 的原始素材，以及 `sn-ppt-creative` 的输入源。

> 注：原始图片（约 2285 张，1.93 GB）已清理，仅保留纯文本。如需图片重新提取，运行 `kaiyuan_pptx_pipeline.py` 即可重跑。
